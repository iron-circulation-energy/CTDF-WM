# Project maintenance

The project is hosted by the [Iron Circulation Energy organization](https://github.com/iron-circulation-energy) in the shared [CTDF-WM repository](https://github.com/iron-circulation-energy/CTDF-WM).

Organization owners manage membership and repository settings. Maintainers review code and data-provenance changes, and contributors propose work through issues and pull requests. Paper author order follows the manuscript; a GitHub role does not change authorship.

Once collaborators have provided their GitHub usernames, organization owners can invite them and assign team-based access. The proposed teams are `maintainers` (Maintain access) and `contributors` (Write access). Give organization ownership only to the people responsible for account administration; two designated owners are recommended for continuity.

Scientific changes should receive review from another maintainer before merging. A paper release should identify the exact commit, verified design-selection artifact, data provenance, test results and archived reproduction outputs. Tags and DOI metadata should be added only after those materials are ready. These are intended practices; this file does not assert that GitHub permissions or branch rules have already been configured.
